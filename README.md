# Agentic AI - Sugam Group

| Folder | What |
|---|---|
| `customer-visit-form/` | Google Apps Script that builds the Customer Visit Google Form (journey steps 01-05), response sheet, and auto-mail to Costing Head + zone Regional Manager. Also a custom HTML web app (`WebApp.gs`, `Index.html`, `Admin.html`, `Approve.html`): admin panel, places from the GR PNL data master, one origin to many destinations, and Costing Head / RM approval with rate. See `SETUP_STEPS.md`. |
| `sugam-journey/` | Customer journey flowchart (visit to collection, 12 steps). |
| `lanes/` | Lane master: origin branches, destinations, lane targets. |
| `main.py` | Email classifier experiment (agree / disagree / review). |
